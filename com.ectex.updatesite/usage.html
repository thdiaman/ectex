Usage guide

Everything you need after installing EcTeX.

Editor and PDF Preview

.tex files open in the EcTeX LaTeX Editor. The PDF Preview view follows the active .tex editor and shows the PDF with the same base name from the same folder. If it is missing, open it with Window > Show View > Other… > EcTeX > PDF Preview; if it opens somewhere unexpected, use Window > Perspective > Reset Perspective. You can drag the view anywhere.

In the PDF Preview: mouse wheel scrolls, Ctrl+wheel (or + / -) zooms, and the right-click menu has Fit Width, Zoom In and Zoom Out.

Build

Default keyCommand
Ctrl+F2Build PDF: saves the file, runs pdflatex -interaction=nonstopmode -file-line-error -synctex=1, and reloads the PDF if it succeeded.
Ctrl+F3Run BibTeX: runs bibtex on the document. It needs the .aux file from an earlier build.

Output goes to the EcTeX Build console. LaTeX errors become problem markers in the editor and the Problems view.

Typical sequence for a document with citations: Build, BibTeX, Build, Build. BibTeX does not rebuild the PDF by itself. For biblatex projects set the bibtex command to biber in the preferences.

Jump between source and PDF (SyncTeX)

  • Source to PDF: put the caret on a line and press Ctrl+Space. The PDF scrolls to the spot and highlights it briefly.
  • PDF to source: Ctrl+click on the text in the PDF Preview, or point at it and press Ctrl+Space. The editor jumps to that line.

Sync uses the .synctex.gz file written by the build. If you compile outside Eclipse, add -synctex=1.

Editing shortcuts

Default keyInserts
Ctrl+B\textbf{}
Ctrl+I\textit{}
Ctrl+U\underline{}
Ctrl+Shift+E\emph{}
Ctrl+Shift+M$ $ (inline math)

With text selected, the command wraps the selection and puts the caret after it; without a selection it inserts the empty pair and puts the caret inside. On macOS, Ctrl in these defaults is Cmd.

Configuration

  • Commands: Window > Preferences > EcTeX sets the pdflatex, bibtex and synctex commands (use a full path if Eclipse does not see them on the PATH) and the arguments for pdflatex and bibtex.
  • Shortcuts: Window > Preferences > General > Keys, then filter by EcTeX. Every command above can be rebound or unbound there. The keys shown in status-line messages always follow your bindings.

Troubleshooting

“Could not run pdflatex”

Eclipse cannot find the program. Install MiKTeX or TeX Live, restart Eclipse so it sees the updated PATH, or enter the full path in Preferences > EcTeX.

Ctrl+Space or Ctrl+click does not jump

Build once with Ctrl+F2 so the .synctex.gz file exists and matches the current text, and make sure synctex is available. The status line shows the reason when a jump fails. Edits since the last build can shift line numbers.

A shortcut does nothing or triggers something else

Open Preferences > General > Keys, filter by the key, and look for conflicts in the Conflicts column. Some systems reserve Ctrl+Space for switching input languages; rebind Synchronize in that case.

The PDF Preview is blank after a build

Look at the EcTeX Build console: if pdflatex failed, the previous PDF stays displayed.

Known limits

  • Sync is reliable for the file being compiled; with \input-ed sub-files, PDF to source can open them, but source to PDF is only supported for the main file.
  • The PDF is rendered at normal resolution, so text can look soft on high-DPI screens.
  • The PDF Preview has no text search.
