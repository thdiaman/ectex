EcTeX – LaTeX for Eclipse

A LaTeX editor with a live PDF Preview, one-key LaTeX builds (with BibTeX or Biber), and jumping between source and PDF with SyncTeX.

  • Editor for .tex files with syntax highlighting
  • PDF Preview view next to the editor (zoom, scroll, highlight of the synced spot)
  • Ctrl+F2 builds the PDF, Ctrl+F3 runs the bibliography tool (BibTeX or Biber), Ctrl+F5 runs Build All (LaTeX, bibliography, LaTeX, LaTeX)
  • Ctrl+Space / Ctrl+click jump between the source and the PDF
  • LaTeX projects: a New LaTeX Project wizard, a LaTeX perspective, and conversion of existing projects
  • Documents split over several files: set a main file per project, and build, BibTeX, the PDF and sync work from every file
  • Productivity shortcuts such as Ctrl+B for \textbf{}; every shortcut is configurable

Requirements

  • Eclipse running on Java 17 or newer. Built and install-tested against Eclipse 2026-03.
  • A TeX distribution (MiKTeX or TeX Live) with pdflatex (or xelatex / lualatex), bibtex (or biber) and synctex on the PATH. If they are not on the PATH, set their locations in Window > Preferences > EcTeX.

Install

  1. In Eclipse choose Help > Install New Software… and click Add…
  2. Enter the name EcTeX and this location: https://thdiaman.github.io/ectex/

    (This is the address this page is served from, without index.html. To install from a downloaded copy instead, use Archive… with ectex-updatesite-<version>.zip, or Local… with the unpacked update-site folder.)

  3. Tick EcTeX – LaTeX Editor and PDF Preview and click Next.
  4. Review the license (EcTeX bundles Apache PDFBox, Apache License 2.0), accept, and click Finish.
  5. Eclipse warns that the content is unsigned; confirm with Install anyway.
  6. Restart Eclipse when asked.

Eclipse downloads the plug-ins that EcTeX depends on (UI, text editor, console) from the standard Eclipse repositories. If it cannot find them, keep Contact all update sites during install to find required software ticked.

First steps

  1. Open or create a .tex file. It opens in the EcTeX LaTeX Editor, and the PDF Preview view opens to its right.
  2. Press Ctrl+F2. The file is saved, pdflatex runs, and the PDF appears.
  3. Press Ctrl+Space in the editor to jump to the matching spot in the PDF, and Ctrl+click in the PDF to jump back to the source.

More in the usage guide.

Update and uninstall

  • Update: Help > Check for Updates (the site must be listed under Preferences > Install/Update > Available Software Sites).
  • Uninstall: Help > About Eclipse IDE > Installation Details > select EcTeX – Split LaTeX Workspace > Uninstall…
